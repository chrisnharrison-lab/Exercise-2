PWA Installation & Setup

  1. Save this file locally as index.html or host it on Netlify / GitHub Pages.
  2. Open the HTTPS link in Safari (iOS) or Chrome (Android).
  3. Tap Share → Add to Home Screen (iOS) or Menu (⋮) → Install App (Android).
  4. Launch directly from your home screen with offline local memory!

Committing Workouts to Memory

When you complete your active workout, click "Commit & Save Session to Graph Memory". Your weight and total reps will be saved directly to your lifetime graph dataset and stored securely in local browser storage.
